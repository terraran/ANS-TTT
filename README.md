# แบบสำรวจเลือกวันซ้อมทีม (Team Day Survey)

หน้าเว็บไฟล์เดียว `index.html` + Google Sheet เป็นฐานข้อมูล ผ่าน Apps Script (`Code.gs`)

- หน้าแรก: เลือกทีม (ทีมหมากรุก / ทีมบอร์ดเกม) → ลิงก์ตรงของแต่ละทีม `index.html#chess`, `index.html#boardgame`
- หน้าทีม: ใส่ชื่อ → ติ๊กช่วงเวลาในตาราง (วัน × 14.30 / 15.45) → ส่ง
- ผลโหวต: ตารางเดียวกัน แสดงแค่ **จำนวนคน** ต่อช่วง (ช่องสีเข้ม = คนเยอะ, กรอบทอง = มากที่สุด) **ไม่แสดงชื่อ**
  — เซิร์ฟเวอร์ไม่ส่งชื่อคนอื่นมาที่หน้าเว็บเลย ชื่อดูได้ใน Sheet เท่านั้น
- ส่งซ้ำด้วยชื่อเดิม = แก้คำตอบ (พิมพ์ชื่อเดิม คำตอบเก่าจะขึ้นมาให้) · มีปุ่มลบคำตอบของฉัน

## ตั้งค่า (ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ (ชื่ออะไรก็ได้)
2. เมนู **ส่วนขยาย → Apps Script** → ลบโค้ดเดิม → วางโค้ดทั้งหมดจาก `Code.gs` → กดบันทึก
3. **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้งานในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
   - กด Deploy → อนุญาตสิทธิ์ (ถ้าขึ้น "Google hasn't verified this app" กด Advanced → Go to … (unsafe) — เป็นสคริปต์ของเราเอง)
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิด `index.html` ใส่ URL ใน `CONFIG.scriptUrl` ด้านบนไฟล์
6. แชร์หน้าเว็บ: อัปโหลด `index.html` ขึ้น GitHub Pages / Netlify Drop หรือที่ไหนก็ได้ที่เปิดเป็นเว็บ

Sheet จะมีแท็บ `chess` และ `boardgame` (สร้างให้อัตโนมัติเมื่อมีคนตอบครั้งแรก): `Timestamp | Name | Slots | Note`
— `Slots` เช่น `mon 14.30,wed 15.45`

## แก้ตัวเลือก

ใน `CONFIG` ของ `index.html`:
- `times` = หัวคอลัมน์เวลา · `days` = แถววัน แต่ละวันใส่ `times` เฉพาะเวลาที่เลือกได้ (ที่ไม่มีจะเป็นช่อง "—")
- `teams` = ทีม — ถ้าเพิ่ม/เปลี่ยน id ต้องแก้ `TEAMS` ใน `Code.gs` ให้ตรงกันด้วย แล้ว deploy เวอร์ชันใหม่
- เปลี่ยนตัวเลือกกลางทาง: คำตอบเก่าที่เลือกช่องที่ถูกลบจะไม่ถูกนับ (ยังอยู่ใน Sheet)

## หมายเหตุ

- ยังไม่ใส่ `scriptUrl` = **โหมดทดลอง** มีข้อมูลตัวอย่าง เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (ใส่ `?mock` ท้าย URL เพื่อบังคับโหมดนี้)
- ผลรีเฟรชเองทุก 30 วินาที (`refreshSeconds`) และทันทีหลังกดส่ง
- แก้ `Code.gs` ภายหลัง ต้อง **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version** URL เดิมถึงจะได้โค้ดใหม่
- ไม่มีล็อกอิน: ใครพิมพ์ชื่อซ้ำกับคนอื่นจะทับ/เห็นคำตอบของคนนั้นได้ — เหมาะกับทีมที่ไว้ใจกัน ถ้าพลาดแก้ใน Sheet ได้โดยตรง
- อยากล้างผล: ลบแถวที่ 2 ลงไปในแท็บของทีมนั้น
- ข้อความที่ขึ้นต้นด้วย `= + - @` ถูกเก็บเป็นข้อความธรรมดา (กันสูตรใน Sheet)
